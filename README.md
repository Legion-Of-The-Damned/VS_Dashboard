# VS Dashboard

**VS Dashboard** — это многофункциональная веб-платформа для сообщества **Legion Of The Damned**, объединяющая сайт клана, панель управления ботом **Void Sentinel**, систему отправки Discord Webhook-сообщений и интерактивный редактор игровых тактик.

Проект создан как единая экосистема для управления кланом, автоматизации процессов и координации участников.

## Основные возможности

### 🌐 Официальный сайт клана

* Главная страница сообщества.
* Информация о клане и его деятельности.
* Новости и объявления.
* Галерея и медиа.
* Ссылки на Discord, GitHub и другие ресурсы.

### 🤖 Панель управления Void Sentinel

Удобный веб-интерфейс для управления Discord-ботом.

Возможности:

* настройка параметров бота;
* управление сервером;
* просмотр статистики;
* управление модулями;
* мониторинг состояния системы;
* централизованная конфигурация.

### 📢 Discord Webhook Manager

Инструмент для создания и отправки красивых Embed-сообщений через Discord Webhooks.

Поддерживаются:

* Embed-сообщения;
* кнопки и компоненты;
* изображения и миниатюры;
* пользовательские цвета;
* предварительный просмотр сообщений;
* шаблоны для быстрого создания публикаций.

### 🗺️ Tactical Map Editor

Интерактивный редактор тактик для игровых карт.

Позволяет:

* создавать собственные тактические схемы;
* размещать метки, маршруты и объекты;
* рисовать планы действий команды;
* сохранять и редактировать тактики;
* делиться готовыми схемами с участниками клана.

## Цель проекта

VS Dashboard объединяет несколько инструментов в одном современном веб-приложении, избавляя участников клана от необходимости использовать множество отдельных сервисов. Вся работа с сайтом, ботом, Discord и игровыми тактиками выполняется через единый интерфейс.

## Для кого создан проект

* участников клана **Legion Of The Damned**;
* администраторов Discord-сервера;
* офицеров и организаторов игровых мероприятий;
* разработчиков проектов сообщества.
